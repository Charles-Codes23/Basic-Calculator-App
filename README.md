# Basic Calculator App
This is a simple calculator project built with HTML, CSS, and JavaScript for performing basic arithmetic operations.

## Features
- Addition
- Substraction
- Multiplication
- Division
- Equal To  (=)
- Clear All Operator

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was created to practise and improve my front-end web development skills.
